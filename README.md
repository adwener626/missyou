# ECHO WORLDS

Интерактивный mobile-first прототип Telegram Mini App. Сейчас его можно открыть в обычном браузере — создавать Telegram-бота для первого запуска не нужно.

## Самый простой запуск

### 1. Установите Node.js

Скачайте **LTS-версию Node.js** с [nodejs.org](https://nodejs.org/) и установите её с настройками по умолчанию.

Проверьте установку в терминале:

```bash
node --version
npm --version
```

Обе команды должны вывести номера версий. Если терминал пишет, что команда не найдена, закройте и заново откройте терминал после установки Node.js.

### 2. Откройте терминал в папке проекта

Папка проекта в текущем окружении:

```bash
cd /workspace/missyou
```

Если вы скачали проект к себе на компьютер, откройте его папку в VS Code, затем выберите **Terminal → New Terminal**. Обычно дополнительная команда `cd` после этого не нужна.

### 3. Запустите прототип

```bash
npm run dev
```

Устанавливать зависимости через `npm install` не требуется. После запуска терминал покажет:

```text
ECHO WORLDS запущен: http://localhost:4173
Остановить сервер: Ctrl+C
```

Откройте [http://localhost:4173](http://localhost:4173) в браузере. Для просмотра в мобильном размере откройте инструменты разработчика (`F12`) и включите режим телефона.

Чтобы остановить приложение, вернитесь в терминал и нажмите `Ctrl+C`.

## Что можно попробовать

1. На экране **«Мир»** нажать **«Забрать»** в карточке «Пока тебя не было».
2. Открыть **«Исследовать»** и запустить первую экспедицию.
3. Перейти в **«Связи»** и посмотреть прототип Player Echo и соседних миров.

Это демонстрационный интерфейс: состояние хранится только до обновления страницы, а настоящий сервер и база данных пока не подключены.

## Полезные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запускает локальный сайт на `http://localhost:4173` |
| `npm test` | запускает автоматические проверки прототипа |
| `npm run build` | собирает готовые статические файлы в папку `dist/` |

Если порт 4173 занят, можно выбрать другой:

**macOS / Linux:**

```bash
PORT=8080 npm run dev
```

**Windows PowerShell:**

```powershell
$env:PORT=8080; npm run dev
```

После этого открывайте `http://localhost:8080`.

## Как открыть именно внутри Telegram

Для публикации как настоящего Mini App позже понадобятся:

1. Telegram-бот, созданный через `@BotFather`.
2. Публичный HTTPS-адрес, на который будет размещена папка `dist/`.
3. Web App URL, указанный в настройках бота через `@BotFather`.

Для локального знакомства с прототипом эти шаги не нужны. Telegram-специфичные вызовы в обычном браузере безопасно пропускаются.
